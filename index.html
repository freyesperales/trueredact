TrueRedact

The black box you drew isn't redaction. This actually deletes the text.

Drawing a black rectangle in Preview or Acrobat leaves the hidden text selectable, searchable and extractable underneath. TrueRedact flattens every page to an image with the boxes burned into the pixels, then rebuilds the PDF — so the text is physically gone. Everything runs in your browser; your file is never uploaded.

Drop a PDF here, or click “Open PDF”

Draw boxes over anything secret. Hit Burn. Download a file where the text under each box no longer exists.

Tip: click a box to select it, drag to move, use the corner handle to resize, press Delete to remove it.

Verification

After burning, TrueRedact re-opens the output and extracts text from it — proving nothing survived.
